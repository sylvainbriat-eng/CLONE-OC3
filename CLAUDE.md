# CLONE OC3

Plugin VST3/AU (JUCE) d'octave basse inspiré du mode POLY de l'OC-3 : seule la note la plus grave, sous la fréquence Range, reçoit une octave basse. Usage personnel de Sylvain, sur Mac avec Ableton Live.

- Sylvain ne code pas : expliquer en français simple, tout livrer prêt à lancer.
- Skills du projet dans `.claude/skills/` : `oc3-octave-poly` (algorithme), `oc3-tests` (banc d'essai), `oc3-plugin-mac` (compilation et installation). Les lire avant de modifier le code correspondant.
- Priorités : suivi fiable dans les accords, latence nulle, bas compact.
- Après toute modification du DSP : lancer le banc d'essai (`oc3-tests`) ; tous les cas doivent rester OK.
